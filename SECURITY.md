# Security Policy

## Reporting

Please open a private security advisory or contact the maintainers if you find
a vulnerability that could expose filing content, local files, credentials, or
confidential review output.

## Data Handling

Do not run confidential, privileged, material non-public, personal, or regulated
documents through this project unless you have reviewed the full local and third
party processing path. The default Markdown and plain text backends run locally.
Optional parser or LLM adapters may involve separate tools or services with
their own terms.

## Secrets

This repository must not contain API keys, access tokens, raw logs, internal
company documents, or private filings.
